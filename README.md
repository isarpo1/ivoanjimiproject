# Visily Platform

Visily is a multi-service platform being developed for the Nigerian market.

## Phase 1

The first version of the platform focuses on short-term rentals.

### MVP Features

- User registration and authentication
- Guest and host profiles
- Property listings
- Property search
- Property images
- Availability
- Bookings
- Payments
- Reviews
- Guest-host messaging

## Planned Technology Stack

### Mobile
Flutter / Dart

### Backend
NestJS / TypeScript

### Database
PostgreSQL

### ORM
Prisma

### Infrastructure
AWS

### Payments
Nigeria-compatible payment provider
